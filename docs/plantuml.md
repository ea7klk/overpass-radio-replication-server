# PlantUML diagrams

The diagrams in this directory are plain PlantUML source and can be rendered
directly by the public PlantUML server:

```text
https://www.plantuml.com/plantuml/svg/
```

Paste the contents of either `.puml` file into the server's editor. They use
only standard PlantUML activity, component, and database syntax; no local
includes or private server extensions are required.

The source files are also renderable locally with:

```bash
plantuml docs/architecture.puml docs/storage.puml
```
